# Related Work 定位笔记(2026-08-28 文献扫描产物)

写 §2 时的划界依据;全部 arXiv 号已网查核实。

## 最近邻与划界(按威胁程度排)

### 1. AVSPO — "Advantage Collapse"(arXiv:2605.21125, ICML 2026)
- **它做了**:命名 advantage collapse(组内奖励同质→优势归零),提出 ACR
  诊断指标(塌陷批占比,早期 ACR 解释终点性能 62% 方差),缓解=注入虚拟
  奖励样本制造非零优势。域:数学 RLVR,0.5B-14B。
- **划界**:①域不同(数学 vs 搜索),无 hop 深度的结构性标度律(我们的
  75/71/84);②其缓解是**内容无关**的——虚拟样本恢复梯度幅值,但塌陷组
  内部排序仍是任意的;我们用特权证据标注恢复**有意义的**排序;③无成本
  病理观察。**引用姿势**:承认命名权,借 ACR 合法化我们的 tie 账本,
  然后打"content-free vs meaningful ordering"这一拳。
- C1 措辞已改:"identify" → "quantify in deep search"(intro 已落实)。

### 2. Search-P1(arXiv:2602.22576, 腾讯, 2026-02)— C2 最近邻
- **它做了**:路径中心奖励(order-agnostic step coverage + 软打分),
  动机句与我们撞车("failed samples contribute nothing");参照物是
  **离线生成的 reference planner 路径**,双轨打分(自一致+参照对齐)。
  自报 +11%。
- **划界**:①参照物是模型生成的参考路径(有偏、需打分模型),我们是
  gold 证据标注(确定性、免 judge);②它无组级机制分析(tie 账本/
  估计器视角);③无边界分析(reachability)。**风险**:审稿人若只读
  摘要会觉得撞车,§2 必须正面列对比表。投稿前应精读其 v1 全文。

### 3. Dark Room(arXiv:2607.21273, 2026-07)— 盟军
- **它做了**:ALFWorld 上自预测密集奖励在 GRPO 下摧毁策略("暗房"退化
  吸收态);根因=全错组常见 + z-score 标准化使塑形系数不变式地放大组内
  残余信号。
- **对我们**:①独立证实"全错组内的残余信号支配学习"——我们成本病理
  观察的姊妹实例(他们是坏填充信号接管,我们是成本项接管);②注意其
  机制依赖 **std 标准化**,我们是 plain LOO(无 std 除法),§3 须一句话
  点明此差异,防审稿人混淆;③强化我们的主张:往全错组里填什么决定一切
  ——所以要填 meaningful 的。intro 已引。

### 4. Stratified GRPO(arXiv:2510.06214, ICML 2026)— 同赛道估计器工作
- 搜索智能体轨迹结构异质→单一全局基线有 cross-stratum bias→按结构分层
  算优势(SAN)。与我们正交:它修"跨题比较的公平性",我们修"同题组内
  的判别性";§2.3 引,一句话划清。

### 5. 缓解家族全景(§2.3 一段话打包)
- 丢弃派:DAPO dynamic sampling(2503.14476)、GRESO(2506.02177)、
  down-sampling(2504.13818)——把打平组扔掉/跳过 = 放弃最难的题;
- 合成派:AVSPO 虚拟样本——可训但排序无意义;
- 结构派:Stratified GRPO、Tree-GRPO(2509.21240, ICLR 2026)——改比较
  结构;
- **我们**:内容派——用特权证据给打平组注入有意义的排序。
  这个"丢弃/合成/结构/内容"四分法本身可以当 §2.3 的组织骨架。
